# Morphii — Feature Overview

*A browser-based custom pin & button designer — no app download, no install. Design on a phone, tablet, or desktop and order in minutes.*

This doc is a reference for marketing/social copy. Everything listed below is actually built and live in the app — nothing here is aspirational unless explicitly marked **(Coming Soon)**.

---

## 1. The Design Experience

### Start fast
- Pick a product, pick a size, and either **start from scratch** or **browse ready-made templates** curated by the shop — no blank-canvas intimidation.
- Runs entirely in the browser. No app store, no account wall to start designing.

### Build the design
Customers layer as many of these elements as they want, freely dragged, resized (pinch, mouse-wheel, or a slider), and rotated:

- **Background** — upload your own photo, or pick from 28+ curated gradient/color presets. Adjustable opacity, drag to reposition, pinch to zoom.
- **Border** — a decorative ring around the edge, from the preset library or your own upload.
- **Character / Mascot** — a centered logo or photo slot, freely movable.
- **Stickers** — preset art library plus custom PNG upload (with one-tap duplicate).
- **Shapes** — 17 built-in vector shapes, recolorable live to any color.
- **Word Art** — ready-made decorative text graphics.
- **Letters** — upload-your-own alphabet sets, browsed by design/font style, then picked letter by letter.
- **Text** — fully custom typed text:
  - A fullscreen text editor with a large live preview (X / checkmark, no jumpy mobile zoom-on-focus)
  - A swipeable 3-row font carousel — the font you land on gets visually bigger as you scroll, so picking a look feels tactile, not like a dropdown
  - Straight or curved (arc) placement, top or bottom
  - 10 quick color swatches plus a full color picker
  - Optional drop shadow

### Fine control, kept simple
- A swipeable strip of icons sits above the pin — tap one to select that element, tap it again to lock it (locked elements show a translucent overlay so you can still tell what's there).
- A **Layers panel** lets you drag to reorder what's on top, lock, or delete anything.
- Live **cut-line / bleed guide** — a warning icon lights up if something's about to get trimmed off, with a popup showing exactly what's at risk.
- **Light/dark theme**, a **full-screen focus mode**, and **paste-a-copied-image-as-a-sticker** for quick edits.

### See it before you order
- A **real 3D preview** — drag to tilt the finished pin around and see it catch the light like a real product photo, with visible edge thickness, before submitting.

### Checkout
- Simple contact form (name, email, phone, notes), instant save code, and an email confirmation — mobile-friendly fields that don't zoom the page when you tap in.

## 3. Behind the Scenes — Order & Fulfillment

*(Useful for "how we run this" content, not just customer-facing copy.)*

- **Live order dashboard** — every submission appears in real time, searchable by save code, email, or name, filterable by product and status (pending / approved / rejected / printed).
- **Batch tools** — select multiple orders at once to bulk-delete or send straight to the print layout tool.
- **Auto-arranging print layout** — drag-and-drop pins onto a standard paper sheet (Letter or A4), sized to true physical bleed, with a visible cut-line guide, then export a print-ready PDF at exact scale.
- **One-click high-res download** — grab any submitted design as a clean, full-resolution PNG (no watermark).
- **Custom font library** — add any Google Font by pasting its link; it's instantly available to every customer in the builder.
- **Catalog controls** — turn any product or size on/off shop-wide without touching code.
- **Finance dashboard** — cost tracking, per-product pricing/margin math, ROI view, and savings goal tracking, all in the same admin screen.

## 4. What Makes It Different (marketing angles)

- **No app to download.** Works on any phone's browser — share a link, start designing.
- **What you design is what prints.** The bleed/cut-line math is calibrated to real button-press machine specs, not a generic guess — so test prints match the screen.
- **Real-time, tactile editing.** Pinch-to-resize, drag-to-tilt 3D preview, and a swipe-to-browse font picker make it feel more like a native app than a web form.
- **Built for a real small business**, not just a demo — the admin side handles the actual day-to-day of running pin orders: fulfillment, printing, pricing, and margins.
